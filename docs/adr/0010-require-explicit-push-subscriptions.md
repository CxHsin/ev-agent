# Require explicit Push Subscriptions

The Agent may deliver proactive content only within a user-confirmed Push Subscription that defines content scope, timing, and delivery. Conversational and behavioral signals may rank items inside that authorization, but cannot create, broaden, accelerate, or extend it; the Agent may only propose a Push Subscription Candidate for confirmation. Subscription state and delivery history belong to the platform, while plugins provide triggers, sources, ranking, generation, and delivery adapters.
